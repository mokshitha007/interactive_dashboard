# 📊 Interactive Sales Dashboard

An interactive business intelligence dashboard built using **Python, Streamlit, Pandas, and Plotly** to analyze sales performance, customer behavior, product trends, and regional performance from the Superstore dataset.

---

## 📌 Project Overview

Organizations generate large volumes of sales data every day. Extracting meaningful insights from this data helps businesses improve decision-making, identify growth opportunities, and optimize performance.

This project provides an interactive dashboard that enables users to:

- Monitor overall sales performance
- Analyze regional and category-wise sales
- Identify top-performing products
- Explore customer segments
- Visualize trends through interactive charts

---

## 🎯 Objectives

- Perform data cleaning and preprocessing
- Conduct exploratory data analysis (EDA)
- Create meaningful Key Performance Indicators (KPIs)
- Develop an interactive dashboard for business insights
- Enable dynamic filtering and visualization

## 📊 Dashboard Features

### 1. Sales Trend Analysis
Visualizes monthly sales performance to identify trends and seasonal patterns.

### 2. Category-wise Sales Analysis
Compares sales across different product categories.

### 3. Region-wise Sales Analysis
Analyzes sales distribution across various geographical regions.

### 4. Customer Segment Analysis
Displays contribution of different customer segments using pie charts.

### 5. Top Products Analysis
Highlights the top-performing products based on sales.

### 6. Interactive Filters
Users can dynamically filter data by:

- Region
- Category

## 🚀 Installation

### Clone Repository

```bash
git clone https://github.com/yourusername/interactive-dashboard.git
```

### Navigate to Project Directory

```bash
cd interactive-dashboard
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

---

## ▶️ Run the Dashboard

```bash
python -m streamlit run app.py
```

The application will launch locally in your browser.
